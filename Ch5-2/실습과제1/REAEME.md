# 실습과제 1
## 참조에 의한 호출과 주소에 의한 호출의 차이점을 설명하라.
| 구분          | 참조에 의한 호출 | 주소에 의한 호출   |
| --------------| --------- | ----------- |
| 사용 방법      | 참조 변수 사용  | 포인터 사용      |
| 문법           | `int& n`  | `int* n`    |
| 함수 호출      | `func(x)` | `func(&x)`  |
| 함수 내부 사용 | 바로 사용 가능  | `*`로 역참조 필요 |
| 가독성         | 더 좋음      | 비교적 복잡      |
| NULL 가능 여부 | 불가능       | 가능          |

## 참조에 의한 호출의 장점은 무엇인가?
- 1. 함수 안에서 값을 변경하면 실제 변수 값도 함께 변경된다.
- 2. 메모리를 절약하고 속도가 빠르다.
