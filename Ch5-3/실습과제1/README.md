# 실습과제1

## 참조에 의한 호출의 장점을 2가지 측면(메모리사용량, 처리시간)에서 설명하시오.
1. 메모리 사용량 감소
> 참조에 의한 호출은 원본 데이터를 그대로 사용하므로 복사본을 만들지 않아 메모리 사용량이 적다.
2. 처리 시간 단축
> 참조에 의한 호출은 참조만 전달하면 되기 때문에 복사 과정이 없어 실행 속도가 더 빠르다.
## C++언어 함수의 반환과정을 상세히 설명하라.
1. 함수 호출
2. 매개변수 전달
3. 함수 내부 실행
4. return 문 실행
5. 반환값 전달
6. 함수 종료 및 메모리 제거
7. 호출한 위치로 복귀
## 반환형이 참조로 선언된 경우 반환값의 의미를 설명하라.
- 반환된 결과가 원본 변수와 같은 메모리 공간을 사용하게 되며 함수 호출 결과를 변수처럼 사용 가능하다.
## 참조 리턴을 응용하는 예제를 인터넷에서 검색하여 실행해보고 설명하시오.
```cpp
#include <iostream>
using namespace std;

int& max_num(int& x, int& y)
{
    if (x > y)
        return x;
    else
        return y;
}

int main()
{
    int a = 10;
    int b = 20;

    cout << "처음 값" << endl;
    cout << "a : " << a << endl;
    cout << "b : " << b << endl;

    max_num(a, b) = 100;

    cout << "\n변경 후" << endl;
    cout << "a : " << a << endl;
    cout << "b : " << b << endl;

    return 0;
}
```
- 반환형이 int& 이므로 함수는 정수값이 아니라 참조를 반환한다. 함수는 b의 참조를 반환하므로 실제 의미는 b = 100; 과 동일하다.
